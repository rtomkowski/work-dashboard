New reminders

Created in Apple Reminders, one per row, each with its own date, time, list and priority. Each batch is tagged so the last one can be undone; other reminders are never edited or deleted.

New rows get
For several at once: separate titles with ; or new lines (Shift+Enter), then press + or Enter to get one row each. ⌘ Enter adds everything to Reminders.

Plan blocks

Time blocks without invitees, shown as Busy. Set the time on a block, or click the calendar to place the selected block. Each block is tagged so the last batch can be undone.

New note

Created in your Obsidian vault. The dashboard only creates notes: an existing note is never changed, and a name that is taken gets a number.
