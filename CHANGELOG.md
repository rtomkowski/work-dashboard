# Changelog

## 1.0.0 (2026-11-09)
First public release, after about 70 private versions in daily use.
- Day, Week (list and time grid), Month, Year, Board, Overdue, Statistics (History and Ahead) and Weekly review views.
- Sources: Apple Calendar and Reminders; optional Obsidian, Jira Cloud and Microsoft Outlook categories; each one can be turned off.
- Plan blocks, batch reminders, new notes, quick capture, Inbox triage, meeting prep, countdown and focus timer.
- Interactive installer (`install.sh`), install guide (`INSTALL.md`), `uninstall.sh --purge`.
